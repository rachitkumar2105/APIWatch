A task API you can watch working.

Every click here sends a real request to a FastAPI backend. The request log shows each one as it happens: the status code, how long it took, and what the server decided.

  • Private accounts. Passwords are stored as bcrypt hashes, and every task request needs a signed token that expires.

  • Retries can't duplicate. Each new task carries an Idempotency-Key, so sending it twice returns the first result.

  • Edits can't overwrite each other. A save based on an old version gets a 409 instead of silently winning.

  • Limits on writes. 30 task changes and 10 sign-ins per minute for each client, enforced by the API.

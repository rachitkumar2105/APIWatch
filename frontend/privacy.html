APIWatch

Privacy

Last updated 16 November 2026

APIWatch is a portfolio demo of a task-management API. It collects as little as it can to work.

What the API stores

  • Your username and a bcrypt hash of your password. The password itself is never stored.
  • The tasks you create: title, details, status, timestamps and a version number.
  • Idempotency keys your browser sends with new tasks, so a retried request can be recognised.

Guest sessions use a randomly generated username and password. Nothing about you is attached to them.

Where it lives

The API runs on Hugging Face Spaces and this site on Vercel. The demo database may be reset at any time, for example when the Space restarts, and everything in it is deleted when that happens. Both hosts keep standard server logs (such as IP addresses and request times) under their own privacy policies.

In your browser

Your sign-in token is kept in this tab’s session storage and is removed when you close the tab or sign out. A guest session also keeps its generated password there so it can renew its token. There are no cookies, no analytics, no ads and no third-party scripts or fonts.

Please don’t

Enter personal, confidential or sensitive information in tasks, or reuse a password you use anywhere else.

Questions or deletion

Open an issue on the project’s GitHub page with your username and the account and its tasks will be deleted.
